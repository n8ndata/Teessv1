ตั้งค่าเชื่อมต่อ Google Sheets (Real-Time Cloud)

ซิงค์บันทึกข้อมูลตารางไปยัง Google Sheet อัตโนมัติในทุกๆ การแก้ไข

วาง Web App URL ที่ได้จากการ Deploy Google Apps Script

การอัปเดตแบบเรียลไทม์ (Auto Real-time Sync):

วิธีสร้าง Google Apps Script เพื่อใช้เชื่อมต่อ (ฟรี):

  1. เปิด Google Sheet ของคุณ → ไปที่เมนู ส่วนขยาย (Extensions) → Apps Script
  2. วางโค้ดสคริปต์เพื่อรับค่า POST (รองรับการเขียนข้อมูลรวมใน Master Sheet เว้นแถวคั่น)
  3. กด การทบทวนตั้งค่า (Deploy) → การสร้างการทบทวนตั้งค่าใหม่ (New Deployment)
  4. เลือกประเภท Web App, ตั้งค่า ใครมีสิทธิ์เข้าถึง: "ทุกคน (Anyone)"
